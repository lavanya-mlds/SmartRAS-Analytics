SmartRAS Analytics

IoT-Based Water Quality Monitoring System for Aquaculture

Abstract

SmartRAS Analytics is an IoT-based water quality monitoring system designed to support small-scale fish farmers. Traditional water monitoring methods require regular manual checking, which can make it difficult to identify sudden changes in water conditions.

The proposed system uses an ESP32 microcontroller and low-cost sensors to monitor water temperature, Total Dissolved Solids (TDS), turbidity, and water level. The collected sensor readings are transmitted through Wi-Fi to a cloud database for storage and monitoring.

A web dashboard is planned to display the readings and help farmers identify changes in water conditions. The system aims to provide an affordable and user-friendly approach to water monitoring, support timely decision-making, and improve water management in aquaculture environments. Future improvements may include automated alerts and advanced data analysis.

Technologies Used

- ESP32 Microcontroller
- Temperature Sensor
- TDS Sensor
- Turbidity Sensor
- Water Level Sensor
- Wi-Fi / IoT Communication
- Cloud Database (Planned)
- Web Dashboard (Planned)

Project Objectives

- Monitor water quality parameters.
- Collect sensor readings using ESP32.
- Support remote monitoring of water conditions.
- Help fish farmers make timely decisions.

Project Status

Hardware integration and software development are in progress. Cloud database integration and dashboard features are planned.

Future Enhancements

- Real-time alerts for abnormal water conditions.
- Cloud-based data visualization.
- Historical data analysis.
- Machine learning-based water quality prediction.
